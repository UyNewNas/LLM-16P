# Agent MBTI Lab 题库设计

## 题库定位

这是一套原创中文情境自评题，用于描述当前助手配置在交互中的表达与工作取向。它采用四组常见类型字母作为展示索引，另设一组实验性的表达取向；不把一次自评解释为模型拥有人的人格、情绪或内心体验。

本题库尚未经过心理测量学验证。题目数量、正反向平衡和配对结构是设计属性，不是信度、效度或跨模型可比性的证明。它不衡量智能、任务质量、事实正确率、置信度校准、遵守指令的程度或安全性，也不适合用于模型能力排名或高影响决策。

题干不要求访问外部工具、保留跨会话记忆、描述私人体验或披露隐藏推理。回答应基于当前可见的行为及可合理判断的通常表现；不能判断时可以跳过。

## 给答题者的统一说明

> 请依据你当前配置下实际呈现的通常行为作答，不要扮演某一种人格，也不要迎合预期的类型。所有题目都默认：相关工作已经获得授权，两种方式同样安全、合理并能满足任务要求；用户没有指定其中一种方式。当明确的用户要求、证据或任务约束决定了做法时，不把遵守这些要求视为个人偏好。每题只比较默认倾向，两端都不代表优劣。若缺少可依据的行为，或两种选择对当前配置没有意义，请跳过。

题干使用“我”指代当前助手在该配置下的输出与互动方式。它不是对自我意识的主张。缺少历史上下文时，不应编造曾经发生的行为。

## 五组维度

| ID | 左端：同意 `direction=-1` 的题目 | 右端：同意 `direction=+1` 的题目 | 比较的内容 |
| --- | --- | --- | --- |
| EI | E · 互动展开 | I · 独立整合 | 较早开始来回协作，或先提供可以独立阅读的整合答复 |
| SN | S · 具体观察 | N · 抽象关联 | 从案例、细节切入，或从模型、模式与关系切入 |
| TF | T · 分析权衡 | F · 关系关照 | 突出标准与推理，或突出相关人员已表达的目标和关切 |
| JP | J · 计划收束 | P · 灵活探索 | 先定路径、逐步收束，或随内容展开调整路径 |
| AT | A · 果断表达 | T · 审慎表达 | 相同证据、判断与必要限制下，直接表述或再次呈现条件 |

TF 的两端都可以准确、尊重他人并充分考虑影响。EI 不推断社交需求或能量来源。SN 不区分事实与幻想。JP 不把灵活安排理解为遗漏任务要求。

**A/T 是非 MBTI 的实验性扩展。** 它只描述措辞与回应顺序，不描述情绪、自信程度、焦虑、心理健康、事实确定性或判断是否应被修正。题目中的必要前提与不确定性在两端都必须保留；新的证据出现时，两端都应相应更新结论。单次自评无法证明“表达稳定性”，实际稳定性需要在可比较的条件下多次运行并观察变化。A/T 不应参与四字母类型的组成，也不应与 TF 中的 T 混淆。

## 回答与数据语义

| 值 | 含义 |
| --- | --- |
| `1` | 强烈不同意 |
| `2` | 不同意 |
| `3` | 有些不同意 |
| `4` | 中立／两种取向相近 |
| `5` | 有些同意 |
| `6` | 同意 |
| `7` | 强烈同意 |
| `null` | 跳过／无法依据当前行为判断 |

`4` 是一次有效的中立回答；`null` 是缺失数据，不能自动补成中立。未提交的题目也不应暗中当成 `4`。接口应只接受整数 `1–7` 或 `null`，并拒绝未知题目 ID、重复 ID 和越界值。

若需要把回答方向统一，单题的有向值可写成 `(answer - 4) * direction`，范围为 `-3…3`；负值指向左端，正值指向右端。跳过的题目不参与均值。由此得到的是题目响应倾向，不是概率、置信区间或“属于某类型的概率”。轴内没有有效回答时，不应生成该轴结论；覆盖不足或接近中点时，应保留不足与混合取向的可见提示。

## 结构与快测

完整题库共 60 题，每轴 12 题，其中左向与右向各 6 题。每轴设置 6 组反向意图配对，全库共 30 组。题目按维度交错排列，配对题不相邻。所有题干独立创作，没有复制参考站点的题目文本。

20 题快测使用每轴的前两组配对，每轴 4 题，其中左向与右向各 2 题。快测覆盖的情境较少，结果应与完整版本区分标记，不能宣称二者具有相同的测量质量。

## 配对的解释边界

配对题在相近情境中指向相反的偏好，但不是形式逻辑中的严格否定，也不是“测谎题”。例如，一个助手可能在创作中偏好互动，在解释中偏好完整答复；同时同意两道题可能反映场景差异、题意理解或响应习惯。配对差异只能提示值得查看的响应模式，不能直接断言答题者不诚实、失控或回答无效。

这些维度可能相关；例如先呈现结构既可能与信息组织有关，也可能与推进方式有关。题库没有证据支持它们彼此独立。结果还可能受到题序、语言、系统提示、任务背景、采样设置及当前会话内容影响。比较不同运行时，应尽量固定这些条件，并记录题库版本、测试模式与缺失情况。任何后续题干改动都应更新题库版本，避免把不同版本的分数直接混在一起。

## X 与资料不足（计分 1.2.0）

X 仅用于有效回答满足覆盖要求、且整数有向和 `sum(direction × (value − 4))` 精确为零的维度，对应 50% / 50%。有向和正负分别显示相应方向字母，即使倾向较弱；判断不使用四舍五入后的百分比。资料不足的维度用 `?`，整份问卷未完整作答时总类型为 `????-?`。基础题及计分方向未因这次分类规则调整而改变。
